โปรเจ็คเราคืออะไร?

Zentest คือแพลตฟอร์มบริหารจัดการการทดสอบซอฟต์แวร์แบบครบวงจร (All-in-one Test Management Platform) ที่ถูกออกแบบมาเพื่อยกระดับประสิทธิภาพการทำงานของ Tester ยุคใหม่

เน้นความรวบรัด ใช้งานง่าย และรองรับทั้ง Functional Testing และ API Testing ในที่เดียว พร้อมระบบ No-code Automation
  • จัดการ Test Case อย่างเป็นระบบ
  • ทดสอบ API ได้ทันที
  • ทำ Automation โดยไม่ต้องเขียนโค้ด
  • สรุปภาพรวมด้วย Dashboard Real-time

บทบาทและหน้าที่ในทีมพัฒนา

Guardian of Quality

ตรวจสอบและควบคุมคุณภาพของซอฟต์แวร์ให้เป็นไปตาม Requirements

Defect Finder

ค้นหาจุดบกพร่อง (Bug) ก่อนที่ซอฟต์แวร์จะถึงมือผู้ใช้งานจริง

Continuous Improver

ให้ Feedback เพื่อนำไปปรับปรุงระบบให้ดียิ่งขึ้น

หน้าที่หลัก:

● เทสหน้าบ้าน (Frontend): ตรวจสอบ UI/UX และการทำงานของหน้าจอ
● เทส API (Backend): ตรวจสอบการรับส่งข้อมูลและความถูกต้องของ Logic

Manual vs Automation

Bug Lifecycle Knowledge

1. Manual Testing

ใช้คนเทสทีละ Step เพื่อดูประสบการณ์ใช้งานจริง (UX) และหาบัคที่ไม่คาดคิด

2. Automation Testing

ใช้เครื่องมือรันสคริปต์แทนคน เหมาะสำหรับงานที่ต้องทำซ้ำๆ และการทำ Regression

Bug Lifecycle: วงจรชีวิตของบัค

พบ (Found)
รายงาน (Report)
Dev แก้ (Fixed)
Re-test
Regression

* การเทสซ้ำเป็นหัวใจสำคัญเพื่อให้มั่นใจว่า "แก้หนึ่งจุด ไม่ทำให้อีกจุดพัง"

ปัญหาที่น่ารำคาญใจของ Tester

การทำตารางใหม่ซ้ำซาก

ต้องสร้างตาราง Test Case ใหม่ทุกครั้งที่เริ่มโปรเจ็ค เสียเวลาเซ็ตอัพที่น่าเบื่อ

การเขียนเอกสารด้วยมือ

ใช้แรงและเวลามากในการบรรยายแต่ละ Step และคาดหวังผลลัพธ์

Regression ที่ใช้เวลานาน

ต้องกลับไปเทสฟังก์ชั่นเก่าซ้ำๆ เพื่อเช็คความปลอดภัย ทำให้งานล้าช้า

Automation ที่ต้องใช้โค้ด

ความยากในการเขียน Script ทำให้ Tester หลายคนเข้าไม่ถึงประสิทธิภาพของมัน

"เราต้องการ เทมเพลตมาตรฐานเดียวกัน เพื่อลดขั้นตอนที่ซ้ำซ้อน"
